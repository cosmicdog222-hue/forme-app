# Forme

**Clothes that understand your shape.**

Forme is a sophisticated fashion-tech app that helps people discover clothing based on their measurements, body shape, and personal style.

Try it live: https://YOUR_USERNAME.github.io/forme

## What It Does

- Enter your body measurements (or skip and use partial data)
- Choose preferences: category, gender, colors, materials, style
- Get personalized recommendations with fit scores and size suggestions
- Search 240+ products (demo database + live Platzi API)
- Save your measurements in your browser for next time

## Key Features

- **Measurement-based fit scoring** — uses actual body measurements, not just size charts
- **Real product data** — integrates with Platzi Fake Store API for live clothing options
- **Smart filters** — filter by category, colors, materials, and style
- **Sophisticated design** — dark premium theme with refined typography
- **Works everywhere** — mobile, tablet, and desktop
- **Privacy-friendly** — measurements stored in your browser, not on a server

## Tech Stack

- Frontend: HTML, CSS (Variables, Grid, Flexbox), Vanilla JavaScript
- Data: Demo database + Platzi Fake Store API
- Storage: Browser localStorage
- Deployment: GitHub Pages

## Getting Started Locally

To run Forme locally:

1. Clone this repo
2. Open `index.html` in a browser, or
3. Serve with a local server:

```bash
# Using Python 3
python3 -m http.server 8000

# Then open http://localhost:8000
```
